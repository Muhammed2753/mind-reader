# Expo Go Setup for Football Game

## Steps:

1. Install Expo CLI:
```bash
npm install -g expo-cli
```

2. Create Expo app:
```bash
cd c:\Users\AJAI MUHAMMED\Desktop\dream
npx create-expo-app football-game
cd football-game
```

3. Copy football_characters.json to the football-game folder

4. Replace App.js with the game code (see App.js in this folder)

5. Start the app:
```bash
npx expo start
```

6. Scan QR code with Expo Go app on your phone

## Install Expo Go on Phone:
- Android: Play Store - "Expo Go"
- iOS: App Store - "Expo Go"
