# Football Game Mobile App Setup

## Prerequisites
```bash
npm install -g expo-cli
```

## Create Expo App
```bash
cd c:\Users\AJAI MUHAMMED\Desktop\dream
npx create-expo-app mobile-app
cd mobile-app
npm install axios
```

## Run on Expo Go
```bash
npx expo start
```

Then scan QR code with Expo Go app on your phone.

## Backend Setup
Your Flask app needs CORS enabled to work with mobile app.
See: dream/app.py (already configured)
